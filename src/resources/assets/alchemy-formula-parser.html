ea_data.lua — How to use

Finding your Mudlet home directory
In Mudlet, run: lua getMudletHomeDir() → it prints the folder path. That's where ea_data.lua needs to live.

New character, inherited alchemy — no trials yet
1. Paste alchemy list 1 – alchemy list 5 output above, click Parse
2. Click Export ea_data.lua → save the file as ea_data.lua in your Mudlet home dir

New character, inherited alchemy — already did some trials
1. Click Import ea_data.lua → browse to your Mudlet home dir and load your existing ea_data.lua
2. Paste alchemy list output above, click Parse (new formulas merge in)
3. Click Export ea_data.lua → save back to your Mudlet home dir, overwriting the old file

The exported file goes to your Mudlet home directory so DMEnchanterAssist can find it.
